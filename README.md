# Bank Account Management System (Java OOP)

A Java application demonstrating fundamental Object-Oriented Programming (OOP) concepts, class structures, encapsulation, and inheritance.

## 📌 Features
- **Object-Oriented Design**: Implements encapsulation and inheritance.
- **Account Data Handling**: Manages client bank account profiles and balance interactions.

## 🛠️ Tech Stack
- **Language**: Java
- **IDE**: Apache NetBeans

## 📂 Repository Files
- `BankAccountPasco.java` - Base bank account class
- `SavingsAccountPasco.java` - Savings account class with interest logic
- `ClientPasco.java` - Main driver class testing client account workflows

## 🚀 How to Run
1. Clone this repository or download the `.java` files.
2. Open the files in **Apache NetBeans** or any Java IDE.
3. Run `ClientPasco.java`.
